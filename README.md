# AI Study Assistant

An AI-powered study assistant built with Python and the Groq API.

## Features
- Explain topics in simple English with examples.
- Summarize study notes.
- Generate five multiple-choice quiz questions.
- Receive AI explanations after answering questions.
- Calculate quiz scores and percentages.
- Save and view quiz history.

## Technologies Used
- Python
- Groq API
- JSON
- python-dotenv

## Installation
Install dependencies using:

    python -m pip install -r requirements.txt

Create a .env file in the project root and add your Groq API key.
Never upload your real API key to GitHub.

## Run the Project

    python src/main.py
